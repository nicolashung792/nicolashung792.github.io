# Updating Jingyi Huang’s homepage

Edit `index.html` to change the introduction, the research interests, the reading list, or the link to Jingyi Huang’s GitHub profile. The page uses HTML, CSS, and local SVG images. It works with JavaScript disabled.

The Reading desk credits each external resource to its author or community. If you add a publication, include its title, all authors, publication or preprint status, and a DOI, arXiv identifier, or publisher link. Confirm the public wording of an affiliation or contact address with the site owner before adding it.

The layout and print styles are in `assets/styles.css`. The illustration in `assets/residue-tree.svg` shows reduction modulo 2, 4, and 8. Update the caption and alternative text in `index.html` if the example changes.

See [deployment and preview instructions](DEPLOYMENT.md) to review a change locally and publish it.
